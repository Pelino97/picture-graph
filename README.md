# 그림 그래프 그리기 📊

초등학교 3학년 수학 「자료의 정리」(그림그래프) 수업용 웹앱이에요.
모둠별로 주제를 정해 설문조사를 하고, 조사 결과를 그림그래프로 직접 그려 보는 활동을 돕습니다.

- 2022 개정 교육과정 [4수04-01] 실생활 자료를 수집하여 간단한 그림그래프나 막대그래프로 나타내고 해석할 수 있다.

## 활동 흐름

1. **인트로**: 캐릭터 '그래피'가 친구들에게 묻고 그림그래프를 완성하는 짧은 애니메이션
2. **주제 정하기**: 모둠(1~8조) 선택 → 추천 주제 7가지 중 고르기 또는 직접 쓰기 → 조사 항목 4가지 (추천 주제는 예시 자동 채움) → 조사할 친구 수(선택)
3. **설문조사**: 주제 캔디바, 2×2 항목 캔디바 → 누르면 확인 팝업, +/− 로 수정, 아래에 투표자 수 실시간 표시
4. **결과 보기**: 결과 표 → 조사가 끝나면 '그림그래프로 그리기' 버튼이 반짝임
5. **그림그래프**: 그림 모양·큰 그림 단위(10명/5명) 고르기 → 큰/작은 그림을 끌어다 놓기(또는 눌러서 놓기) → 확인하기(틀리면 고칠 점 안내) → 알게 된 점 쓰기 → 화이트보드 전체 화면

## 내 컴퓨터에서 실행하기

```bash
npm install     # 처음 한 번
npm run dev     # 개발용 실행 → 브라우저에서 http://localhost:5173
npm test        # 채점·저장 로직 자동 테스트
npm run build   # 배포용 파일 만들기 (dist 폴더)
```

## 배포 (GitHub → Vercel)

1. GitHub에 빈 저장소를 만들고 이 폴더를 올립니다.
2. vercel.com 에서 GitHub로 로그인 → **Add New → Project** → 저장소 **Import**
3. Framework Preset이 **Vite** 로 잡혀 있는지 확인 → **Deploy**
4. 이후에는 GitHub에 올릴 때마다 자동으로 다시 배포돼요.

## 안전 설계

- 서버, 로그인, 데이터베이스가 없는 **정적 웹앱**이에요. 학생 이름 등 개인정보를 받지 않아요.
- 입력 내용은 그 기기의 브라우저(localStorage)에만 저장되고 어디로도 전송되지 않아요. '새로 시작'을 누르면 지워져요.
- 외부 글꼴·스크립트·분석 도구를 불러오지 않아요.
- `vercel.json` 에 보안 헤더(CSP, 클릭재킹 방지, HTTPS 강제 등)를 설정했어요.
- 입력 글자 수 제한, 저장된 값 검증, React의 자동 이스케이프로 스크립트 삽입(XSS)을 막아요.
